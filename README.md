# GrinyaVerse · Личный выпуск

Личный сайт Гриши с интерактивной журнальной обложкой. React + React Router + Vite, обычный JavaScript и CSS.

## Запуск на компьютере

Нужен Node.js 22.13 или новее. Открой папку проекта в VS Code и выполни в терминале:

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite, обычно http://localhost:5173.

## Сборка для сервера

```sh
npm run build
npm run preview
```

После сборки папка `dist/` содержит готовый сайт. Можно загрузить её содержимое на VPS в каталог Nginx. Исходники редактируются в `src/`, а `dist/` каждый раз создаётся заново.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `index.html` | HTML-документ, в который React вставляет приложение |
| `src/main.jsx` | Подключение React, маршрутизатора и стилей |
| `src/App.jsx` | Список страниц и их адресов |
| `src/pages/` | Главная, обо мне, проекты, чаевые и страница 404 |
| `src/components/layout/` | Оболочка сайта; шапка и подвал показываются только на внутренних страницах |
| `src/components/home/` | Обложка и переиспользуемая ссылка-заголовок раздела |
| `src/components/common/` | Общие небольшие компоненты и обработка переходов |
| `src/data/` | Номер выпуска, дата, заголовки страниц и тексты проектов |
| `src/styles/` | Стили, разделённые по назначению |
| `public/assets/` | Фотографии, вырезанный портрет и локальный шрифт |
| `scripts/create-route-entries.mjs` | HTML-входы для открытия внутренних страниц напрямую |
| `vite.config.js` | Настройки разработки и сборки |

## Как приложение собирается в страницу

1. Браузер загружает `index.html`, в котором находится пустой элемент `#root`.
2. `src/main.jsx` создаёт React-приложение внутри `#root`, подключает маршрутизатор и общий файл стилей.
3. `src/App.jsx` сопоставляет адрес со страницей: `/`, `/about/`, `/projects/` или `/tips/`.
4. `SiteLayout.jsx` определяет оболочку: главная занимает весь экран, на внутренних страницах остаются общие шапка и подвал. `<Outlet />` подставляет выбранную страницу.
5. Главная страница состоит только из `Poster.jsx`. Кликабельные журнальные заголовки создаёт `CoverNavLink.jsx`. Для узкого вертикального экрана `<picture>` выбирает отдельную композицию фотографии.
6. Тексты и метаданные, которые удобно менять без правки разметки, лежат в `src/data/`.
7. `src/styles/index.css` подключает базу, общий макет, обложку, подвал и внутренние страницы. Адаптация обложки находится рядом с её стилями в `home.css`, остальных страниц — в `responsive.css`.

## Как устроены переходы

`BrowserRouter` отслеживает адрес. `Routes` выбирает страницу. Компонент `Link` меняет адрес без полной перезагрузки документа. Для публикации по пути вида `/about/` скрипт сборки также создаёт `dist/about/index.html`.

`RouteEffects.jsx` после каждого перехода меняет заголовок вкладки и цвет интерфейса браузера, прокручивает страницу вверх и возвращает клавиатурный фокус в основное содержимое.

## Где менять сайт

- Главная композиция: `src/components/home/Poster.jsx`.
- Пункты навигации на обложке: `src/components/home/CoverNavLink.jsx`.
- Тексты проектов: `src/data/projects.js`.
- Дата и номер выпуска: `src/data/site.js`.
- Цвета и шрифт: `src/styles/base.css`.
- Обложка и её мобильная версия: `src/styles/home.css`.
- Адаптация внутренних страниц: `src/styles/responsive.css`.
- Фото обложки: `public/assets/grisha-autumn-editorial.jpg` и `public/assets/grisha-autumn-editorial-mobile.jpg`.
- Журнальные шрифты: Bodoni Moda и Cormorant Garamond в `public/assets/fonts/`, подключения — в `src/styles/base.css`. Лицензии OFL сохранены рядом.

## Нужен ли здесь SCSS

Пока нет. В проекте уже используются CSS-переменные для цветов и шрифтов, а стили разделены по назначению. Для текущего объёма обычный CSS проще: не нужна новая зависимость, отдельная компиляция и ещё один синтаксис.

Переход на SCSS станет полезен, если появятся десятки компонентов со своими файлами, сложные повторяющиеся миксины или несколько полноценных тем. До этого момента больше пользы даст дальнейшее разделение крупных файлов или CSS Modules, если понадобится жёсткая изоляция имён классов.

## Что уже работает

Главная, `/about/`, `/projects/`, `/tips/`, переходы назад/вперёд, мобильная вёрстка и локальные изображения. Платёжная ссылка пока не подключена: страница чаевых сообщает об этом явно.

Никаких API-ключей и серверной базы для запуска не требуется. Фото и шрифты загружаются локально, без внешних запросов. Фотографии личные; перед их повторным использованием нужно разрешение владельца. Лицензия старого шрифта находится в `public/assets/font-license.txt`, новых — в `public/assets/fonts/`. Осенние фотографии обработаны с помощью ИИ на основе предоставленного портрета: фон и некоторые детали отличаются от исходника.
