# PaperMenu3D

Настоящий WebGL-лист в существующем header. Добавлена только Three.js 0.183.2; React Three Fiber не нужен для одной сцены с рендером по требованию. Остальные страницы и оформление сохранены.

## Настройка

`npm ci`, затем `npm run dev`. Откройте меню и панель «Бумага · настройки». В ней доступны Crumple, Macro folds, Medium folds, Micro wrinkles, Edge curl, Light intensity, Shadow и Paper roughness. Панель и окно `window.__paperMenuDev` отсутствуют в production.

Все исходные параметры находятся в `src/components/paper-menu/paperConfig.js`: плотность сетки, остаточная мятость, время, силы складок, цвет, шероховатость, свет, тени и предел DPR.

## Ответственность модулей

- `PaperMenu3D.jsx`: интеграция React, portal, native dialog для фокуса и клавиатуры, переходы, fallback.
- `PaperScene.js`: WebGL renderer, камера, свет, тени, адаптация, lifecycle и рендер по требованию.
- `paperFields.js`: детерминированные macro/medium/micro-поля и загнутые края.
- `paperShaders.js`: GPU-деформация, региональные задержки и нормали по производным деформированной поверхности. Основные складки формируются геометрией.
- `PaperMaterial.js`: PBR-бумага и согласованная геометрия depth-pass.
- `PaperMenuTexture.js`: текст и фокус как CanvasTexture на поверхности; бумажное зерно.
- `paperHitTest.js`: CPU-копия деформации для raycasting. Пересчитывается после анимации и изменения размера, а не каждый кадр.
- `paperAnimation.js`: разные последовательности раскрытия и закрытия. Конечная мятость 0.27; короткое оседание 0.255 → 0.29 → 0.27.

Мобильная сетка 80×120, desktop 120×180. Слабые устройства переходят на 64×96 и DPR 1, а при слишком медленном рендере получают обычные доступные ссылки. При отсутствии WebGL 2 сохраняется функциональное меню. Учтены reduced motion, visibilitychange, resize, orientation, освобождение ресурсов и остановка RAF в покое.

«Работа» ведёт на `/projects/#work`. Для будущего preview «Обо мне» предусмотрен `onSelect(item)`: возврат `false` оставляет меню открытым и отменяет переход. Текущий вариант ведёт на `/about/`.

## Проверка

`npm run test:paper` проверяет границы и финальное значение анимации, детерминированность, объём открытого листа, собирание геометрии в комок и попадание raycaster во все четыре пункта. `npm run build` проверяет production-сборку и создаёт входы внутренних страниц.

В этой среде браузер не предоставляет WebGL. В браузере проверены fallback, Escape, возврат фокуса, клавиатурная навигация, переход к работе и мобильные размеры 390×844, 320×700 и 844×390. WebGL-сцена отдельно отрисована настоящим WebGL 2 через Mesa EGL: шейдеры скомпилированы, GL errors отсутствуют. Результаты в `docs/previews/paper-menu3d-*` являются рендерами сцены, а не скриншотами браузера. Производительность и сенсорный ввод на физическом iPhone/Android ещё нужно проверить.

## Технические границы

Это процедурная модель памяти складок, а не симулятор столкновений листа с самим собой. В открытом состоянии используются реальные нормали, геометрические складки и падающая тень. Самозатенение открытого тонкого листа отключено для устранения shadow acne на мобильных картах теней; у собранного комка оно включено. Впадины дополнительно слегка затемняются в материале. Это решение даёт цельную поверхность без видимой сетки.
