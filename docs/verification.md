# Проверка осеннего выпуска

- `npm run build` проходит.
- В локальном Chromium проверены `/`, `/about/`, `/projects/`, `/tips/` на ширинах 320, 390, 700, 768, 1000 и 1440 px: нет горизонтального переполнения, все изображения декодируются.
- Проверены открытие меню, Escape, возврат фокуса, переход из меню, окно знакомства и восстановление прокрутки после перехода.
- Переключение направлений чаевых обновляет текст.
- При `prefers-reduced-motion: reduce` анимация отключена, диалог закрывается.
- Ошибок JavaScript и HTTP 4xx/5xx в этих проверках нет.
- Все русские буквы А-Я/а-я и Ё/ё присутствуют в каждом WOFF2.

Анимация бумаги стилизована средствами CSS. Её вид на iOS Safari ещё не проверен на реальном устройстве.

Для завершения наполнения нужны ссылки на личные YouTube, TikTok, Telegram и на перевод. Новые изображения и готовые скриншоты находятся в репозитории. Публикация на VPS в эту проверку не входит.
